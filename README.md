### 2. Security Hash
**Python | Hashing | Security Testing**

An educational MD5 hash-testing tool that demonstrates dictionary-based password recovery against supplied hash values.

- MD5 hash generation and comparison.
- Customizable candidate wordlists.
- Results reporting and CSV export.
- Interactive Google Colab interface.
